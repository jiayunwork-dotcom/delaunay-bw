# delaunay-bw

Bowyer–Watson 平面点集 Delaunay 三角剖分核算工具，附带 Voronoi 对偶图。

输入一组二维点（JSON），本工具在后端按 Bowyer–Watson 算法从超三角形开始逐点插入：标记外接圆包含新点的三角形、挖洞、重连，输出时剥掉超三角形相关单元。同时给出对偶：每个三角形外心即 Voronoi 顶点，共享边的相邻三角形外心连成对偶边。返回数据保证三个性质同时成立——每个三角形外接圆内不含其他点（空圆属性）、三角形并集覆盖凸包、Voronoi 顶点落在三角形外心。

非法输入（点数不足 3、重复点、坐标含 NaN、全共线）返回明确的错误文案；四点共圆的情形按容差稳定处理，不翻边振荡。本仓是网格剖分内核，不做画板或 GIS 编辑产品，也不涉及杆端力或刚度矩阵。

## 用法

```bash
go run . -http :8080
```

浏览器打开 http://localhost:8080 ：页面预置 `example/grid-jitter.json`（5×4 微扰网格，20 点），点击「加载示例」填充坐标，点击「计算」后由后端返回三角形索引并在 SVG 中绘制三角网，同时列出三角形数、凸包顶点数与面积核算。也可手工输入坐标。失败路径（重复点、共线、NaN、点数不足）在页面错误区原样显示后端返回的 error 文案。

### HTTP 接口

- `POST /api/triangulate` — 点集 → 三角形索引、是否 Delaunay、三角形数、凸包边数与面积核算。
  请求：`{"points":[{"x":0,"y":0},{"x":1,"y":0},{"x":0,"y":1}]}`。
  返回：`{"triangles":[[0,1,2]],"delaunay":true,"count":1,"hull_size":3,"area":0.5,...}`。
- `POST /api/voronoi` — 点集 → Voronoi 顶点（外心）与对偶边。
  请求同上。返回：`{"vertices":[{"x":0.5,"y":0.5}],"edges":[],"count":1}`。
- `GET /example/grid-jitter.json` — 预置微扰网格算例。
- 非法输入返回 HTTP 400，错误体形如 `{"error":"..."}`。

三角形数钉住了欧拉公式：`T = 2n - 2 - h`，其中 n 为点数、h 为凸包边数；凸包内部每增加一点，三角形数增加 2。

## 关键约定

- 超三角形顶点附加在输入点之后（索引 n、n+1、n+2），输出前剥除，不会出现在结果里。
- 外接圆判定用行列式 in-circle 测试加相对容差；洞边界提取后统一逆时针定向，避免挖洞重连绕向相反。
- 默认容差 1e-9（相对）；可通过请求体 `tolerance` 覆盖。
